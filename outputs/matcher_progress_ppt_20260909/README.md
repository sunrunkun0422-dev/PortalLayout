13 页，16:9，白底、暗红与灰色，建议 12–15 分钟。第 3–7 页以原五类 Matcher 案例为核心；后续呈现物理特征、开口类型辅助匹配、受控实验计划，最后单列长走廊多视图子图设想。

文字、矩阵、表格与示意图可以编辑。全景和局部候选图复用冻结案例图片，使用 PPT 原生裁切；原图片未修改。所有原始分数、选择和 GT 标记保持不变。新增方法均明确标为建议或待验证，长走廊图是概念示意。

`source_manifest.json` 保存数据来源、SHA-256、参考资料与输入未变校验。`slide_specs.json` 保存逐页说明；PPT 备注也包含讲述边界和引用。此次没有运行训练、模型推理或 test 评价。

复现入口：`build_ppt.py`（依赖 python-pptx；本次临时安装在 `/tmp/bi_layout_ppt_deps`，未改动项目训练环境）。PDF 使用本机 LibreOffice 导出。
