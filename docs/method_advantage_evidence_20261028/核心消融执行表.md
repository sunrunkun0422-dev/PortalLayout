## 必须先补的接口

- 单图上下文独立开关：关闭时同时屏蔽融合分支与 gate 的上下文输入，保持其他分支不变。只屏蔽分支会通过 gate 泄露上下文信息。
- 检索独立开关：关闭时跳过 query/二维记忆检索，检索打分通道置零，保留描述子/几何打分。不得用历史 legacy matcher 替代该组。
- 将开关写入 checkpoint 配置、恢复契约与特征缓存身份；拒绝跨组缓存复用。现有累进 ablation 不能实现这一设计。
