# 可复用提示词：开题技术路线与论文对比

请为我的硕士开题预演制作基于真实论文与当前代码的技术路线材料。输入是同层全部全景图，目标是多房间平面布局；研究一为开口引导的可靠跨房间视觉匹配，研究二为可靠跨图观测约束的局部布局几何修正。

**本轮只读研究代码、配置、现有实验和 PPT，只在 `docs/proposal_method_comparison/` 新增或更新汇报材料。不要运行训练、模型推理或评价，不修改算法、训练控制、缓存与权重。**

按以下顺序直接完成：

1. 核查当前工作区实际调用链及最新实验契约。旧文件名、旧设计和历史 PPT 仅作为线索，不能代替现行实现。记录检查时间、分支、提交与关键文件哈希；逐模块列输入、输出、来源、函数和行号。
2. 阅读 SALVe 原论文 §4、Fig. 2–3 和官方代码，核对输入假设、几何提案、RGB BEV 验证、定位及轮廓融合。补充核对 Bi-Layout、CoVisPose 和直接相关布局工作，明确自己的机制是否已有先例。
3. 分开标记“代码已实现／部分实现／拟研究／待核实”与“效果是否有实验证据”。研究二必须检查是否真的改变局部墙段／端点；不要把 PGO、区域并集或单图端点拟合当成完整跨图几何优化。
4. 生成四张中文 16:9 图：SALVe 原流程、现有项目真实流程、包含两个研究点的完整论文主图、SALVe 与本课题上下双泳道对比。节点采用全景观测，房间在关联后形成；无可靠连接保留分量。每张附 Mermaid、SVG 和 3840×2160 PNG，图文状态一致。
5. 输出技术对比、代码证据、实验验证设计、一分钟及逐图讲稿、至少八个导师追问，以及浏览入口。图片文字要简短，来源与实现细节放配套文档。

必须纠正：“SALVe 只用几何”。它已有视觉对齐验证和轮廓融合。比较重点是视觉证据进入对应判断的阶段、判别对象、拒绝机制和局部几何优化变量。把“候选对条件化开口证据检索”和“可靠跨图观测约束局部结构更新”作为待检验假设，不把更多特征、Attention、Sinkhorn 或换骨干单独称为创新。

当前开口结构采样不能默认是精确门框；开口邻域注意力不能默认是共同可见空间；几何 BEV 不能称 RGB 重投影。unknown 不作负例；GT 只进入离线监督／评价。实现完成、候选上限提升、连通率上升和可靠重建成功必须分开。

实验设计仅写方案：固定输入与监督的表征／检索消融、对应到位姿误差分解、研究二局部收益与非共享区域退化、最终七指标。原生 SALVe 与统一前端适配基线分开；legacy Matcher 不是 SALVe。保留尺度、对齐协议、开发集使用及预训练曝光限制。未经实验不要写“优于 SALVe”。
