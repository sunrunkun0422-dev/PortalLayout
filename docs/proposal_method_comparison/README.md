## 明天预演怎么用

1. 先读 [一分钟讲稿](开题预演讲稿.md)，修正“ SALVe 只有几何”的说法。
2. 依次展示四张图，明确“当前实现”与“最终论文目标”的区别。
3. 重点准备 [导师追问](导师可能追问.md) 中关于视觉创新、PGO、共视和当前效果的回答。
4. 有时间再读 [技术对比](技术对比分析.md) 和 [验证设计](实验验证设计.md)。源码追问可查 [证据清单](代码证据清单.md)。

本材料的核心结论：研究一已经实现，但可靠接边效果尚未建立；研究二仍为拟研究。不得把“候选上限改善”改写为“最终多房间重建成功”，也没有当前方法优于 SALVe 的公平实验结论。

- 检查日期 2026-10-26；源码与输入指纹见 [证据 manifest](evidence_manifest.json)。原 PPT 第 10–14 页已直接读取 XML，并与现有提取文本核对。

- 已有 Matplotlib 和 Noto 中文字体用于导出，不安装依赖。无本地 Mermaid 渲染器，Mermaid 做节点、连边和基本语法检查；SVG/PNG 实际由 Matplotlib 导出，**不声称已用 Mermaid 引擎渲染验证**。
- [交付检查记录](delivery_checks.json) 记录图片大小、链接、输入哈希与材料范围。本轮没有执行训练、推理、评估或项目回归测试，也未修改运行服务。
