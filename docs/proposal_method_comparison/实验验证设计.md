## 1. 共同条件与比较轨道

- 延续现有 60 层、house 级 fit/selection/calibration 划分。selection 用于选方法及权重；已看过的 calibration 只称开发验证集。正式结论另需冻结配置后的独立房屋测试，不能事后把开发集改称测试集。
- 固定 Bi-Layout、Opening Head、候选身份、冻结特征和局部预测几何。几何方案改变时，明确区分“只替换位姿输入”和“重新编码特征”，不让一次消融改变多个因素。
- unknown 不当负例；几何弱标签与人工审核标签分表。跨房、同房及归属未知分别统计；GT 只生成离线标签或评价，不进入推理特征、选边和聚类。
- **系统轨道**：原生 SALVe 与完整本系统，统一评价楼层、输入全景、尺度来源及指标定义；单独报告各自前端、监督量和预训练曝光。未实际复现前仅给方法对比。
- **模块轨道**：同一冻结前端、相同候选和后端，只替换关联／验证机制。移植的 SALVe 风格模块必须称“适配基线”，不冒充原论文结果。legacy Matcher 是本项目旧模型，不是 SALVe。
- 论文原始数值保留其原协议；尤其不能与本项目“主分量单锚点规范”的 S 轨道直接拼成胜负表。[SALVe §5.3 的评价对齐](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136910632.pdf)

## 2. 研究一：可靠对应是否真的改善

| 实验 | 控制变量 | 主要观察与失败判据 |
|---|---|---|
| 候选召回上限 | 固定角域 IoU、双向唯一和歧义规则 | 开口检测／关联不到标注的正例保留分母；分清候选漏检与 Matcher 漏配 |
| 单图表征消融 | 基础池化 → 加结构 → 加上下文 → 加几何 → 加图内注意力；另做上下文单独移除 | 比较固定精确率下跨房召回；逐房屋公开结果，不能只按所有单元汇总 |
| 候选对检索消融 | 同一单图描述子与评分容量；比较无跨图检索、仅源条件、源目标共同条件 | 验证目标候选条件是否有增益；不能只用注意力热图作证 |
| 无匹配判别 | 固定监督及采样；assignment、margin、known-cell 目标对照 | 已知 P/R、明确负例图像对误接受率、unknown 接受数；取消 dustbin 仅作诊断 |
| 证据泛化 | 房屋划分、不同开口宽度、低共视、重复纹理分层 | 判断是否依赖同房／房屋外观捷径；共视分层只能在有离线可验证标签时使用 |
| 对应到位姿传播 | GT 几何求解、已知对应+预测几何、实际预测候选、最终选解四级 | 正确对应不等于正确位姿；报告固定图像对集合的可解比例与最终正确接边率 |

匹配指标：候选召回、已知对应精确率／召回率、按房屋宏平均跨房 AP、图像对关联 P/R/F1、明确无对应对误接受率。AP 分母包含所有弱正单元；unknown 不作为假正例，无已知正例房屋单列误接受。弱标签上的“已知精确率”不能称为全体样本真实精确率。

位姿指标：双向归一化平移、圆周旋转、相对尺度误差，另报正确候选上限、位姿验证 P/R、错误桥边及各分量。沿用已批准工作点门槛，失败时保留无接边结果，不以展示完整为由放宽。

## 3. 研究二：局部修正的增益与代价

先限定问题：固定可信对应及当前位姿，以墙段方向／位置和开口沿墙端点为变量，保持拓扑连接顺序。只使用有证据的共同物理结构，其他房间墙面不强行对齐。实施前还需明确有效观测构造与残差，当前不声称已有可用优化器。

顺序对照：

1. **几何可辨识性**：人工可核算双房场景，单开口、多开口、不同墙厚／遮挡、无共视；检查约束是否唯一、哪些变量只能靠先验。
2. **局部上限**：GT 对应＋合格位姿下优化预测局部几何；保持初始布局为对照。GT 仅进入标为 Oracle 的离线组。
3. **误差分解**：逐一替换 GT 对应、开口几何或位姿，分清监督错误、不可观测性与几何预测误差。完整 GT 仍失败的案例单列核查。
4. **实际输入**：使用冻结研究一的预测对应，加入置信度／可见性及鲁棒权重；与相同输入但不修正几何比较。
5. **结构保持消融**：去除本图锚定、跨图项或结构项，检查共享区域增益是否伴随非共享区域退化。加入错误匹配压力测试。
6. **整体后果**：分别报告局部修正、仅 PGO、局部修正后重估位姿＋PGO，不能把整个位姿改善全部归功于形状修正。

局部指标：单图 2D IoU、开口端点距离、支撑墙位置／方向误差、共享开口一致性、非共享区域误差变化、无效多边形／自交／退化／回退比例。米制尺度缺失时只报归一化误差，不伪造厘米值。

## 4. 七项整层指标与口径

最终沿用当前 `floor-metrics.v2` 实现，主分量由预测决定，S 轨道仅使用其锚点完成一次规范；缺失分量仍留在 GT 分母。下表是验收定义，不是当前成绩。

| 指标 | 固定口径 |
|---|---|
| 整体 IoU ↑ | 主分量预测区域并集与全部目标 GT 房间并集 |
| 定位覆盖率 ↑ | 平移 ≤50 cm 且旋转 ≤10° 的非锚点观测／全部可评价非锚点观测 |
| 平移误差 cm ↓ | 主分量有效非锚点的误差中位数，包含定位错误的观测 |
| 旋转误差 ° ↓ | 同集合的圆周角误差中位数 |
| Wall F1 ↑ | 规范化分隔边界图；端点 ≤20 cm、方向 ≤5°、重叠 ≥0.5，一对一最大基数匹配 |
| Junction F1 ↑ | 10 cm 阈值，一对一最大基数再最小距离匹配 |
| 墙体距离 cm ↓ | 双向长度加权点到墙段距离，2 cm 采样，200 cm 截断 |

两侧独立进行 5 cm 吸附、交点切分、去重与 3° 度二共线简化。门洞不从主分隔墙图裁掉。IoU、覆盖、F1、墙距按楼层宏平均；位姿主列为观测级 pooled median，附均值、P90 和有效数。另报连通覆盖、正确／错误／忽略边、房间恢复、分量及失败楼层。

房屋 1289 无米制尺度：厘米指标及依赖厘米阈值的指标为 N/A；旋转仍可评价，提供归一化平移诊断。没有定位到有效非锚点时误差 N/A，不写成 0。单观测楼层覆盖率 N/A。

## 5. 结论与统计纪律

固定候选集合与图像对分母，按 house 做配对汇总和 bootstrap 区间；有效工作点建立后再增加多 seed。预先固定较好、中位、失败案例选取规则并公开全部楼层，失败不删除。前端、开口阈值、几何策略、模型权重、训练种子、协议种子与校准绑定均写入实验契约。

预期证据链是“模块改变 → 对应／几何改善 → 正确接边改善 → 整层收益”。任一步不成立都应保留结论，而不是用另一项更好看的指标代替。原生 SALVe 的公平实验、研究二有效性和独立留出泛化目前均待完成。
