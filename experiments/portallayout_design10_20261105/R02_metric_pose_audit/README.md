# R02：米制相对位姿诊断

在新队列 selection 的冻结探索性预测上，按 50 cm／10° 评价相对位姿。评价时使用 GT 锚点尺度将预测和真值的局部位移换算成米；GT 未用于预测和选边。完整结果及来源哈希见 [report.json](report.json) 和 `pairs.jsonl`。

3,651 个跨房间图像对中，3,227 对具备米制 GT；共输出 230 个位姿，其中 188 个有米制 GT 可评价，18 个同时满足 50 cm／10°。另有 42 个已输出位姿缺少米制尺度，3,421 对没有输出位姿。

这些输出是未校准的探索性候选，不代表可靠接受边；位姿达标也不自动说明两个房间具有可通行连接。3,651 包含本来不应匹配的房间对，因此没有位姿不等同于错误。前端训练数据存在房屋暴露，本结果只用于开发诊断。
