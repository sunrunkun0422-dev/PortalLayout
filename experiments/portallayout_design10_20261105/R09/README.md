# R09 候选对照：离线规范

状态：**规范与模拟测试已完成；真实候选转换和方法比较未完成。**

`tools/research10_candidate_comparison.py` 接收冻结图像对清单与两种方法已转换、无 GT 的候选 JSON，确认双方声明相同坐标契约；对无向图像对按固定顺序将 `T_B_to_A` 必要时求逆，对合法 Sim(2) 位姿按容差去重，记录来源开口，写出统一候选 ID 的两份验证器输入。无法转换、缺失图像对、无法评分和未报告均保留在各自分母。评分结果必须绑定并集指纹。候选、评分 JSON 使用严格白名单，输入路径和标识不能包含 GT 分类标签。

规范字段及调用样例以 [可执行测试](../../../tests/test_research10_candidate_comparison.py) 和脚本中的版本化常量为准。工具不读取 GT、不生成候选、不运行验证器；输入声明的相同坐标系并不等于已实证转换正确。历史 SALVe 的 R/t/s 与现有 GT 标签分类目录不可直接作为规范输入，需要另行验证图像 ID、开口身份、尺度、方向及无标签导出。任何缺失映射或分数都不能静默删除；不能根据当前规范宣称 SALVe 对照已完成或方法更优。

`tools/research10_portal_candidate_export.py` 将已冻结的预测结果转为候选接口，检查产物指纹及固定图像对分母；[一个真实三图楼层烟雾](portal_native_export_smoke/provenance.json)保留 3 个图像对和 2 个原生候选。候选包括被探索性筛选器标记不可用的假设，导出不表示接边正确。坐标为 `bi_panorama_local_xz`、相机高度归一化，尚未验证与 SALVe 坐标和尺度的关系。

`tools/research10_salve_union_scores.py` 将无标签四图评分绑定到冻结并集，记录输入与源码哈希，并对缺失渲染和失败评分计数。[官方四图和合成并集接口烟雾](union_fixture_smoke/README.md)为 1/1 评分，概率与该官方样例一致；该合成并集不对应真实渲染，不能作为对比结果。对应测试 22 项通过。真实 SALVe 候选转换、两方法候选渲染及同候选模型评分仍未完成。

[SALVe 上游审计](salve_upstream_audit.md)已定位预测 W/D/O 路径中的 GT 位姿图、GT 相机高度读取和标签目录写入；必须先替换这些依赖，再声称同候选推理独立于 GT。
