# 候选并集到 SALVe 验证器的烟雾检查

`synthetic_union.json` 是测试构造的候选并集，`fixture_manifest.json` 指向中性目录下的官方验证器四图样例；二者只用于检查输入绑定，不表示该变换生成了这些图片。最终记录为 `result_v4/`：1 个候选全部评分，概率为 `0.9624085426330566`，与历史同一图像样例一致。输出记录 union 指纹、输入、图像、相关源码和验证器权重哈希。`result/`、`result_v2/`、`result_v3/` 是本次调试期间的旧版本，保留但不作为最终复核依据。

适配器会拒绝并集指纹不一致、并集外候选和标签目录路径，将缺失图像、未提供渲染、评分失败分别计入分母。它不生成候选或 BEV 图像，也不能证明上游渲染不依赖 GT 或坐标转换正确，因此这不是 SALVe 系统结果或公平对照。
