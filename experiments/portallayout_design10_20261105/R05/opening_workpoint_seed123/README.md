# R05：开口工作点诊断

使用 R04 固定的单种子 checkpoint、R01 的 selection 与 calibration 房屋以及自动几何弱标签，按 `opening-cross-room.v2` 搜索阈值。结果为 **calibration_infeasible**：没有阈值同时满足精确率、已知负对误接受率、跨房召回和支持数量要求；没有产生已校准阈值。

校准集包含 687 个已知弱正候选格，其中 283 个跨房；另有 636 个已知负图像对。逐条件失败次数和完整工作点结果见 [matching_report.json](matching_report.json)，每对分数与标签见 `matching_report.pairs.jsonl`。

仅作故障诊断，在**阈值 0**时，校准集跨房间有 119 个接受弱正、848 个接受弱负及 412 个接受未知；629 个已知负对中 223 对被接受。该点不是严格工作点，也不表示人工核实的精度或可用接边。

当前数据中的 Opening Head 存在已确认房屋暴露；人工核验未完成。即使将来获得弱标签工作点，也不能将其直接声称为端到端未见房屋精度。由于本轮无可行阈值，不运行 audit 阈值复核，也不进入严格接边或正式训练。

[固定阈值失败分析](failure_analysis.json)仅用于理解误差：校准集跨房间在 0.9 时接受 3 个弱正、18 个弱负、6 个未知；在 0.95 时接受 0 个弱正、5 个弱负、2 个未知。它们不是获选工作点。由于已经查看这些结果并据此安排后续目标对照，这批 calibration 房屋今后应视为开发数据；新方案确定后需重新保留独立校准房屋。
